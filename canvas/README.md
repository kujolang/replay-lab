# Replay Lab canvas

Replay Lab is a local Kujo execution workbench. The twelve records on startup come from the checked-in snapshot, which was generated by running the same scenario commands used by the browser. A small loopback server runs those commands again when you use the toolbar.

## Launch

On macOS or Linux, install Node.js 22 or newer and [Kujo 1.9.0](https://github.com/kujolang/kujo/releases/tag/v1.9.0). From a parent directory containing the Replay Lab clone, obtain the two sibling tools.

```sh
git clone https://github.com/kujolang/eval.git
git -C eval checkout c1b263a10702c2fa8ab61ed507029a6bfec2e03d
git clone https://github.com/kujolang/dispatch.git
git -C dispatch checkout 18b5c737a73904ae942f0bd1c3baa1f77c2bfb40
cd replay-lab/canvas
npm start
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173). Set `KUJO_BIN` for a runtime outside `PATH`, `EVAL_ROOT` and `DISPATCH_ROOT` for differently located checkouts, or `PORT` to use another local port. Use absolute paths for the overrides. No credentials, paid API calls, application dependency installation, or build step are required to launch.

## Scenarios

| Action | What it runs | Reproduce from `canvas/` |
| --- | --- | --- |
| Replay | Replays a recorded scripted classifier response in native strict mode through two policy configurations. Compare lists changed decision fields and checks the replay against the previously published baseline. | `npm run prepare:scenarios -- replay` |
| Evaluate | Replays the input and runs three Kujo Eval assertions against the resulting decisions. The suite and individual check cards show the native report fields. | `npm run prepare:scenarios -- evaluate` |
| Execute | Starts the Dispatch Routed Review workflow in offline fixture mode. The planner and finalize steps expose recorded event sequences. The run inspector includes native state, trace, report and estimated accounting. | `npm run prepare:scenarios -- execute` |

The prepare commands print JSON. Run `npm run prepare:scenarios -- --write` to refresh the starting snapshot. The historical RunLedger receipt describes the earlier 200-candidate study and has separate provenance. The recorded response was captured from a local scripted HTTP provider. [Record a new native cassette](../docs/CUSTOM_REPLAY.md) using the existing CLI.

Drag to pan. Scroll or pinch to zoom around the pointer or gesture midpoint. Use arrow keys, plus and minus, and Home when the canvas has focus. Fit returns to the starting view. Use the inspector selector to access cards at any zoom. Clicking blank space produces a ripple. The synthetic stress test is a separate field with its own density controls and device readout. Pause freezes animation. The app starts paused when the OS requests reduced motion.

## Verify and capture

```sh
npm ci
npx playwright install ffmpeg
TEST_NATIVE=1 npm test
npm run test:browser
npm run benchmark
npm run capture
```

Browser scripts use installed Google Chrome. To use Playwright Chromium, run `npx playwright install chromium` and set `CHROME_CHANNEL=bundled`. Set `HEADED=1` to measure or capture a visible Chrome window. Set `BENCHMARK_MS` to change the sample length or `ARTIFACT_DIR` to retain measurements separately. The scripts start an isolated local server and close it and Chrome after each run.
